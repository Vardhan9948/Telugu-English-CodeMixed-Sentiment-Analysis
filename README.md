# Telugu-English Code-Mixed Sentiment Analysis

A beginner-friendly NLP project for sentiment classification of Telugu-English code-mixed text.

This is a small educational baseline trained on 40 example sentences in
`data/telugu_english_sentiment.csv`. Its reported score is only a demonstration
and should not be treated as evidence of real-world performance. The current
normalizer keeps Latin letters and digits, so Telugu written in Telugu script
is removed during preprocessing.

## Baseline
- Text normalization
- TF-IDF features
- Logistic Regression classifier
- Accuracy, precision, recall and F1-score
- Confusion matrix
- Interactive prediction

## Run in VS Code

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python src/train.py
python src/predict.py
```

If PowerShell blocks activation, use:
```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe src/train.py
.\.venv\Scripts\python.exe src/predict.py
```

## Research extension
Compare the baseline with transliteration normalization and multilingual transformer models such as mBERT, XLM-R or IndicBERT.

## Project files
- `src/`: text normalization, model training and interactive prediction
- `data/`: example labeled dataset
- `outputs/`: saved baseline model, vectorizer and evaluation artifacts
- `presentation/` and the project `.pptx`/`.docx` files: presentation and report materials

The model and vectorizer in `outputs/` are generated by `python src/train.py`.
